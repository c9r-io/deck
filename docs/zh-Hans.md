# deck 简体中文指南

deck 是用于管理终端 agent session 的原生 macOS 应用。每张卡片都对应一个真实、持久的 tmux session；Board 用于表达当前需要关注的工作，而不是自动改变任务状态。

## 快速开始

从 GitHub Releases 下载 `.dmg` 并拖入“应用程序”即可。应用已内置 tmux，无需另行安装。首次创建项目时，默认 Board 会按当前语言命名为“需要关注 / 进行中 / 队列中 / 已搁置”；创建后这些名称就是你的数据，切换语言不会改名。

- 点击“新建 session”进入 shell。
- shell 回到提示符时，deck 会低频保存当前目录和一段有上限的纯文本输出；
  机器重启后重新打开卡片，会在该目录创建新 shell，并在只读历史层中显示旧输出。
  deck 不会重放命令，也不会恢复进程、环境变量或 agent 画面。可在“设置 → Shell 恢复”中关闭或清除。
- 拖动卡片可更换 Board；点击 Board 空白处可指定新 session 的位置。
- 双击标题可重命名，右键卡片可编辑说明或关闭 session。
- 用 ⌘D / ⌘⇧D 拆分窗格；关闭窗格不会终止 session。
- 定时 prompt 支持指定时间、在上一项安静 3 分钟后发送，以及周期规则。“安静”仅表示没有输出，不表示任务完成或正在等待输入。
- 若 deck 在发送期间停止，结果会显示为“无法确认是否已发送”。系统不会自动重试；请确认已发送，或在接受重复发送风险后手动重试。

语言可在“设置 → 语言”中选择“跟随系统 / English / 简体中文”，无需重启。

## 更新通道

Stable 是默认更新通道，只接收正式版本。需要提前体验候选版本时，可在
“设置 → 更新通道”中选择 Nightly 并确认风险；Nightly 经过相同的签名和
Apple 公证，但仍可能不稳定。版本号旁会显示当前通道和短 commit，反馈问题
时请一并提供。

Nightly 与 Stable 使用同一个应用、`~/.deck` 数据和 tmux session，不能同时
运行。安装 Nightly 前请备份重要数据。切回 Stable 只影响之后的更新检查，
不会自动降级；如果当前 Nightly 版本更高，需要重新安装 Stable DMG，同时仍
须遵守 future-schema/data compatibility 规则。维护者流程、恢复方法和信任
边界见[发布通道说明](release-channels.md)。
