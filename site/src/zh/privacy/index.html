deck 应用

deck 无需账号，也不上传终端 prompt、命令、路径、session 名、project 名、repository 名或终端输出。应用状态保存在本机 ~/.deck。诊断日志只使用封闭事件码并经过脱敏，保存在本机，仅在你主动选择时导出。

这个网站

deck.c9r.io 第一版不使用 cookie、广告追踪、fingerprinting、分析脚本、表单或第三方字体。服务器和托管服务商可能处理交付页面所必需的普通网络 metadata。网站不会尝试把访问或下载与应用安装关联。

外部链接

下载、源码和反馈托管在 GitHub。访问这些链接后适用 GitHub 的隐私条款。除非 GitHub 另有提示，反馈内容会公开。请勿在 issue 中包含 secret、终端输出、私有路径、repository 名或其他敏感内容。

问题和删除

网站不保存 deck 专属用户档案，因此没有需要删除的网站档案。退出 deck 后删除 ~/.deck 即可移除应用数据。如有问题，可以使用反馈 issue 表单，但请勿包含敏感内容。
