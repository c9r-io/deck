deck 应用

deck 是本地终端的界面，不提供云服务或云账号，也没有托管任务的远端服务器。终端里的 prompt、命令、路径、session 名称和输出不会上传给 deck，应用数据保存在本机 ~/.deck。终端由本机的 tmux 后台服务运行，不需要部署服务器。你使用的 CLI 可能会连接模型供应商或其他服务，相关数据如何处理，取决于该 CLI 及你的账号设置。

语音与可选集成

语音识别在你的 Mac 上完成。如果本机暂时无法识别，deck 会提示原因，不会改用云端服务。首次使用某种语言时，Apple 可能需要下载相应的语言资源。deck 不会把录音或转写内容写入磁盘。已确认的文字会直接输入所选终端，不替你按回车；终端里的程序可能按自己的规则处理这些文字。

启用 Claude Code 或 Codex 的状态集成后，deck 会在 ~/.claude/settings.json 或 ~/.codex/hooks.json 中添加自己的 hook；关闭时只移除这几项。这些 hook 只回传一个固定状态词、窗格标识和 agent 的不透明轮次 ID，不包含 prompt、输出或路径。可选 Slack 连接读取你自己的表情反应事件，或按明确规则匹配频道消息。匹配的频道文字会存入卡片暂存区；第一条匹配消息还可能触发已保存的模板，后续笔记不会自动发送；deck 从不向 Slack 发送消息。可选的手机 Connector 在选定的私有网络地址监听配对设备；已配对手机可读取符合条件的 agent 卡片输出并请求发送 prompt 或启动已保存的任务预设。可选的 MCP client 只得到本机明确授权的 Deck 权限。独立的 Deck Tunnel Helper 将 OpenAI Runtime API key 存入 macOS 钥匙串，并在你启动时通过官方 tunnel-client 建立出站连接。Slack 令牌和 MCP client 凭据也存于钥匙串，不写入 ~/.deck。手机 Connector 的 TLS 私钥保存在钥匙串中，deck 对每台已配对手机的令牌只保存哈希值。「离席时通知我」默认关闭；开启后，macOS 通知只显示卡片标题、项目名称和一句固定说明，不包含 prompt、输出或路径。可选的「本地翻译」在本机运行：你确认后，它会从 Mozilla 的公开存储下载固定的 English → 简体中文离线语言包，翻译时不会把文字发往任何地方。「复制内容」页只读取选中该页且 Deck 在前台时新复制的文字，来源应用标记为私密的复制内容不会读取。更新检查和发行版下载会连接 GitHub。

本地数据与日志

列表、卡片暂存区和还没完成的人工检查点会保留所需文字，方便发送和检查。诊断日志只记录经过脱敏的事件信息，保存在本机，可按需要手动导出。Shell 恢复默认关闭；启用后会保留有大小上限、尽力脱敏的输出快照，最多七天。脱敏不保证移除所有敏感内容。

通过设置里的独立入口清除命令历史、恢复快照或日志。重置日志不会停止 session 或清除其他数据。移除应用数据前，先妥善结束工作，并通过设置关闭相关集成。仅删除 ~/.deck 不会移除钥匙串令牌、CLI hook 配置，也不会结束独立的 tmux 服务；需要保留工作时请先备份。

这个网站

网站不使用 Cookie、广告追踪、设备指纹、访问分析脚本、表单或第三方字体。为正常提供网页，托管服务商可能处理必要的网络请求信息。网站不会把浏览、下载记录与应用安装关联起来。

外部链接与反馈

下载、源码和反馈托管在 GitHub，适用其政策。Issue 通常公开，分享前请检查文字、截图和导出日志，去掉凭据、私有路径与真实任务内容。
