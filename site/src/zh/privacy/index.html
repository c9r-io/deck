deck 应用

deck 是本地终端的界面，不提供云服务或云账号，也没有托管任务的远端服务器。终端里的 prompt、命令、路径、session 名称和输出不会上传给 deck，应用数据保存在本机 ~/.deck。终端由本机的 tmux 后台服务运行，不需要部署服务器。你使用的 CLI 可能会连接模型供应商或其他服务，相关数据如何处理，取决于该 CLI 及你的账号设置。

语音与可选集成

语音识别在你的 Mac 上完成。如果本机暂时无法识别，deck 会提示原因，不会改用云端服务。首次使用某种语言时，Apple 可能需要下载相应的语言资源。deck 不会把录音或未发送草稿保存到磁盘；草稿只在本次应用运行中保留。只有点击「仅插入」或「发送」时，文字才会进入所选 CLI。

启用 Claude Code 或 Codex 的状态集成后，deck 会在相应 CLI 的配置中添加 hook。这些 hook 只回传固定状态词和窗格标识，不包含 prompt 或输出。可选 Slack 集成连接 Slack，读取你的表情反应事件及匹配消息；消息正文会成为本地待发送 prompt 的一部分，deck 不会自动回复 Slack。Slack 令牌保存在 macOS 钥匙串，不会写入 ~/.deck。更新检查和发行版下载会连接 GitHub。

本地数据与日志

列表和还没完成的人工检查点会保留所需的 prompt，方便发送和检查。诊断日志只记录经过脱敏的事件信息，保存在本机，可按需要手动导出。Shell 恢复默认关闭；启用后会保留有大小上限、尽力脱敏的输出快照，最多七天。脱敏不保证移除所有敏感内容。

通过设置里的独立入口清除命令历史、恢复快照或日志。重置日志不会停止 session 或清除其他数据。移除应用数据前，先妥善结束工作，并通过设置关闭相关集成。仅删除 ~/.deck 不会移除钥匙串令牌、CLI hook 配置，也不会结束独立的 tmux 服务；需要保留工作时请先备份。

这个网站

网站不使用 Cookie、广告追踪、设备指纹、访问分析脚本、表单或第三方字体。为正常提供网页，托管服务商可能处理必要的网络请求信息。网站不会把浏览、下载记录与应用安装关联起来。

外部链接与反馈

下载、源码和反馈托管在 GitHub，适用其政策。Issue 通常公开，分享前请检查文字、截图和导出日志，去掉凭据、私有路径与真实任务内容。
