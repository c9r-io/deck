deck 应用

deck 无需账号或云工作区，不会把终端 prompt、命令、路径、session 名或输出上传到 deck 服务。应用状态保存在本机 ~/.deck。你选择的 CLI 可能连接它自己的模型供应商或其他服务，适用该 CLI 的数据处理方式与账号设置。

语音与可选集成

语音在你的 Mac 上识别，没有云端语音回退。首次需要时，Apple 可能下载语言资源。deck 不会把录音或未发送草稿保存到磁盘；草稿只在本次应用运行中保留。只有你明确插入或发送时，文字才会进入所选 CLI。

可选的 Claude Code 与 Codex hook 只报告固定状态词和 pane 标识，不报告 prompt 或输出；启用会更新相应 CLI 配置。可选 Slack 集成连接 Slack，读取你的表情反应事件及匹配消息；消息正文会成为本地待发送 prompt 的一部分，deck 不会自动回复 Slack。Slack 令牌保存在 macOS 钥匙串，位于 ~/.deck 之外。更新检查和发行版下载会连接 GitHub。

本地数据与日志

列表及待检查点包含执行或检查所需的 prompt 文字。诊断日志使用结构化、脱敏事件并留在本机，只有你主动选择时才导出。Shell 恢复默认关闭；启用后会保留有大小上限、尽力脱敏的输出快照，最多七天。脱敏不保证移除所有敏感内容。

通过设置里的独立入口清除命令历史、恢复快照或日志。重置日志不会停止 session 或清除其他数据。移除应用数据前，先妥善结束工作，并通过设置关闭相关集成。仅删除 ~/.deck 不会移除钥匙串令牌、CLI hook 配置，也不会结束独立的 tmux 服务；需要保留工作时请先备份。

这个网站

网站不使用 cookie、广告追踪、fingerprinting、分析脚本、表单或第三方字体。托管服务商可能处理交付页面所必需的普通网络 metadata。网站不会把访问或下载与应用安装关联。

外部链接与反馈

下载、源码和反馈托管在 GitHub，适用其政策。Issue 通常公开，分享前请检查文字、截图和导出日志，去掉凭据、私有路径与真实任务内容。
