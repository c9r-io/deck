离开前

知道什么会继续。

我需要一直开着 deck 吗？

应用必须运行，列表才能投递、自动化才能启动。私有 tmux 中的 session 可以在退出应用后继续存活；机器或服务重启会结束原进程。

查看指南 →

安静代表 agent 准备好了吗？

无有效 agent 状态时，琥珀色只说明 session 已经安静。安静不等于 READY。启用相应 Claude Code 或 Codex 状态集成可接收明确报告；本轮结束仍不证明任务成功。

查看指南 →

打开结果就会发送下一条吗？

打开只会把已报告的本轮结束标为已读。启用人工检查的列表仍等待你明确确认，之后还会检查时间与目标条件。

查看指南 →

应用里包含 agent 吗？

应用已内置 tmux。Agent CLI 需要自行安装配置，也可以使用任意能在 macOS 终端交互运行的命令。Agent 账号和模型访问由相应工具管理。
