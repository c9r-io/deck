Basic use

Use it as an ordinary terminal.

No agent integration or automation setup is needed. If you open several sessions, the board gives you a way to keep them organized.

01 · Terminal

Open a session

Each card opens a local terminal. Run shell commands, scripts or an installed CLI such as Claude Code or Codex, as you normally would.

Getting started →
02 · Organization

Group your sessions

Arrange sessions by project and group, give cards recognizable names, and click one to return to its terminal. Cards stay where you put them; status changes do not move them.

Using the board →
03 · Status

Check session activity

Cards show terminal activity. With a supported agent integration enabled, Needs attention also gathers reported input requests and unread turn endings. Check the actual output to judge whether a task succeeded.

Optional features

Arrange prompts for later.

If you often send follow-up prompts into the same session, put them in a list with timing and waiting conditions. You can enable inspection after each row to review results before continuing. Ordinary terminal use does not require any of this setup.

No cloud workspace.

deck has no cloud service, cloud account or remote server hosting your tasks. Sessions and app data live on your Mac. Your CLI may contact its own model provider; optional Slack integration connects to Slack, and update checks connect to GitHub.

Common questions

Do I need to keep deck running?

The app must be running for lists to deliver and automations to start. Sessions in private tmux survive quitting the app; a machine or service restart ends their processes.

Read the guide →

Does quiet mean the agent is ready?

Without a valid agent report, amber means the session has been quiet. Quiet is not ready. Enable the matching Claude Code or Codex status integration for explicit reports; a turn ending still does not prove task success.

Read the guide →

Will opening a result let the next prompt run?

Opening marks a reported turn ending as read. A list with human inspection enabled waits for your explicit confirmation, and then still checks its time and target conditions.

Read the guide →

Are agent CLIs included?

tmux is included. Install and configure your own agent CLI, or use any interactive command that works in a macOS terminal. Agent accounts and model access are managed by those tools.
