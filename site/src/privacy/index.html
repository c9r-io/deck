Privacy

Local work stays local.

Updated: 2026-09-11 · deck 0.6.6

The deck app

deck is an interface for local terminals, with no cloud service, cloud account or remote server hosting your tasks. It does not upload terminal prompts, commands, paths, session names or output to a deck service. Application state is stored locally under ~/.deck. Terminals run through a local tmux background process; there is no server for you to deploy. Your chosen CLI may contact its own model provider or other services; its data handling and account settings apply.

Voice and optional integrations

Voice recognition runs on your Mac, with no cloud speech fallback. Apple may download language assets when needed. Recordings and unsent drafts are not saved to disk by deck; drafts last only for the current app run. Text reaches the selected CLI only when you explicitly insert or send it.

Optional Claude Code and Codex hooks report fixed status words and pane identifiers, not prompts or output. Enabling them updates the respective CLI configuration. Optional Slack integration connects to Slack to read your reaction events and matching messages. Message text becomes part of the local queued prompt; deck does not automatically write replies to Slack. Slack tokens are stored in macOS Keychain, outside ~/.deck. Update checks and release downloads connect to GitHub.

Local data and logs

Lists and pending inspection checkpoints contain the prompt text needed to run or review them. Diagnostic logs use structured, sanitized events and remain local; export is an explicit action. Shell recovery is off by default. If enabled, it keeps bounded, best-effort-redacted output snapshots for up to seven days. Redaction may not remove every secret.

Use the separate Settings controls to clear command history, recovery snapshots or logs. Resetting logs does not stop sessions or clear other data. Before removing application data, stop work deliberately and disable integrations through Settings. Deleting ~/.deck alone neither removes Keychain tokens and CLI hook configuration nor terminates the independent tmux server. Keep a backup if you need to retain your work.

This website

This website uses no cookies, advertising trackers, fingerprinting, analytics scripts, forms or third-party fonts. Hosting providers may process ordinary network metadata needed to deliver pages. The website does not link visits or downloads to app installations.

External links and feedback

Downloads, source and feedback are hosted on GitHub and subject to its policies. Issues are normally public. Check any text, screenshot or log export before sharing; remove credentials, private paths and real task content.
