Privacy

Local work stays local.

Last updated: 2026-08-30

The deck app

deck does not require an account and does not upload terminal prompts, commands, paths, session names, project names, repository names, or terminal output. Application state is stored locally under ~/.deck. Diagnostic logs use closed event codes and redaction; they are stored locally and can be exported only when you choose.

This website

The first version of deck.c9r.io uses no cookies, advertising trackers, fingerprinting, analytics scripts, forms, or third-party fonts. The server and hosting provider may process ordinary network metadata required to deliver the page. This site does not attempt to connect a visit or download with an app installation.

External links

Downloads, source code, and feedback are hosted on GitHub. When you follow those links, GitHub’s privacy terms apply. Feedback is public unless GitHub indicates otherwise. Do not include secrets, terminal output, private paths, repository names, or other sensitive content in an issue.

Questions and deletion

The website stores no deck-specific user profile to delete. App data can be removed locally by deleting ~/.deck after quitting deck. For questions, use the feedback issue form without including sensitive content.
