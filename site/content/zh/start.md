# 开始第一个任务

打开一个 session 就能像普通终端一样使用 deck。每张卡片对应本机上的一个终端，返回看板后，里面的程序仍会继续运行。

## 安装与准备

1. [下载稳定版](https://github.com/c9r-io/deck/releases/latest)，打开 DMG，把 deck 拖入「应用程序」。发行版经过签名和 Apple 公证，当前支持 Apple Silicon Mac。
2. 打开 deck。无需 deck 账号，tmux 已包含在应用中。
3. 可以直接使用 shell，无需开启额外功能。如果要运行 agent，再安装和登录相应 CLI；其模型服务和费用由相应工具提供和收取。

## 创建并运行

1. 选择项目，点击「＋ 新建 session」。未设置项目默认值时，会在你的个人目录打开 shell。
2. 在终端中照常运行命令。例如，用 `pwd` 查看当前目录，用 `ls` 查看文件，再用 `cd` 进入工作目录。也可以运行已经安装好的 `claude` 或 `codex`。
3. 按平时的方式运行脚本或给 agent 输入任务。双击标题可重命名，例如「检查变更」。
4. 点击返回按钮回到看板。终端中的程序继续运行；再次点击卡片即可返回。

看板里的栏目可以按自己的习惯分组。拖动卡片可以调整位置；点击某个栏目的空白处，新建的 session 就会放进该栏目。卡片不会随着状态变化自动移动。

## 设置常用目录和命令

从「新建 session ▾ → 项目默认值…」设置默认目录和启动命令，也可右键项目标签打开。之后「＋」或 ⌘N 会使用这些默认值，首次启动时发送一次命令。

「仅新建 shell」保留项目默认目录，但不发送默认命令。从路径菜单或卡片的「在此目录新建」创建的 session 使用该处的目录，并且只启动 shell。

目录已经不存在时，deck 会让你取消、修改默认值，或在个人目录打开 shell；不会把失败的启动保存成一张新卡片。

## 什么时候回来

同时运行几个任务时，可以从侧边栏「待关注」查看哪些 agent 在等回复、哪些本轮结果还没看。需要先启用相应 agent 的状态集成；未启用时，deck 只能根据终端有没有输出提供活动信息。[了解状态集成 →](/zh/guide/attention/)

> 没有收到状态报告的 session，可能不会出现在「待关注」中。因此，列表为空并不表示所有任务都已完成。

## 返回看板与关闭卡片

返回看板或关闭分屏窗格，只是收起终端画面。**关闭卡片会结束对应 session**，并取消它的待发送列表。想暂时离开终端时，使用返回按钮即可。

退出应用后，session 仍会继续运行，但 deck 暂停发送列表中的 prompt。重启机器或升级时重启后台服务的影响，见[离开、关闭与恢复](/zh/guide/sessions/)。
