# 开始第一个任务

在一个真实终端里开始工作，再回到看板。每张卡片对应一个持久的 session。

## 安装与准备

1. [下载稳定版](https://github.com/c9r-io/deck/releases/latest)，打开 DMG，把 deck 拖入「应用程序」。发行版经过签名和 Apple 公证，当前支持 Apple Silicon Mac。
2. 打开 deck。无需 deck 账号，tmux 已包含在应用中。
3. 准备你要运行的 CLI。deck 提供终端与管理界面；agent 的安装、登录、模型访问和费用由相应 CLI 决定。也可以先用普通 shell 熟悉操作。

## 创建并运行

1. 选择项目，点击「＋ 新建 session」。未设置项目默认值时，会在你的个人目录打开 shell。
2. 在终端中进入工作目录，运行已安装的 CLI，例如 `claude` 或 `codex`。
3. 像在普通终端中一样输入任务。双击标题可重命名，例如「检查变更」。
4. 点击返回按钮回到看板。agent 继续在原 session 中运行；再次点击卡片即可返回。

看板里的栏目是手工分组。拖动卡片改变它的位置；点击栏目空白处可指定新 session 的目标栏目。卡片状态变化不会自动搬动卡片。

## 省去下次重复启动

从「新建 session ▾ → 项目默认值…」设置默认目录和启动命令，也可右键项目标签打开。之后「＋」或 ⌘N 会使用这些默认值，首次启动时发送一次命令。

「仅新建 shell」保留项目默认目录，但不发送默认命令。从路径菜单或卡片的「在此目录新建」创建的 session 使用该处的目录，并且只启动 shell。

目录已经不存在时，deck 会让你取消、修改默认值，或在个人目录打开 shell；不会把失败的启动保存成一张新卡片。

## 什么时候回来

可以先去做另一件事，再从侧边栏「待关注」检查跨项目的输入请求和本轮结束未读。明确的 agent 状态依赖相应集成；未启用时只能观察输出活动。[设置与理解状态 →](/zh/guide/attention/)

> 「待关注」为空不等于所有任务都完成了。没有有效状态报告的 session 仍可能需要你查看。

## 离开前分清操作

返回看板或关闭分屏窗格会离开终端视图。**关闭卡片会结束对应 session**，并取消它的待发送列表；不要把它当作收起窗口。

退出应用后，session 继续存活，但 deck 不再投递列表。机器重启和升级服务重启有不同结果，见[离开、关闭与恢复](/zh/guide/sessions/)。
