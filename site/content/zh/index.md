# 使用指南

让任务继续，把注意力留给需要你判断的时刻。从第一个 session 开始，需要时再查具体操作。

## 先完成一个任务

[开始第一个任务 →](/zh/guide/start/)

创建 session、启动你已有的 CLI，然后离开终端再回来。deck 已内置 tmux，无需单独安装；Claude Code、Codex 等 CLI 需要你自行安装和配置。

## 记住这三个区别

- **看板分组由你决定。** 栏目名称、卡片位置和顺序不会跟随实时状态自动变化；侧边栏的「待关注」另行汇总跨项目的信号。
- **投递与任务结果分开。** 已发送只说明输入已投递；安静、本轮结束和人工检查分别表达不同的事实。
- **session 与应用各有生命周期。** 退出 deck 后，底层 session 通常继续存活；列表与自动化则需要 deck 运行才能投递或触发。

## 版本范围

本指南以 **deck 0.6.5** 的功能为基线，适用于 **0.6.6 Stable**，涵盖待关注、列表、人工检查点、自动化与本机语音草稿。请先在设置中核对安装版本；旧版的名称和入口可能不同。0.6.6 改善了 prompt 投递的隐私保护，没有新增操作流程。之后的 Nightly 改动不作为本指南中的既有能力。

升级、切换通道及旧版数据兼容性，见[更新与版本](/zh/guide/input-and-settings/#更新与版本)。
