从打开第一个 session，到安排后续 prompt、查看任务状态，这里介绍 deck 的日常用法。可以从头开始，也可以直接查找遇到的问题。

## 先完成一个任务

[开始第一个任务 →](/zh/guide/start/)

先用一个平时就在做的任务熟悉 deck：创建 session，启动常用的 CLI，再试试返回看板、查看进展。deck 已内置 tmux；Claude Code、Codex 等 CLI 需要另外安装和配置。

## 几个基本概念

- **看板用来整理 session。** 栏目由你命名，卡片由你摆放，不会随着状态变化自动移动。「待关注」会另外汇总各个项目的状态信息。
- **发送进度和任务结果是两回事。** 「已发送」只说明 prompt 已经发出；程序是否还在工作、结果是否符合预期，需要结合状态和实际内容判断。
- **退出应用不会结束 session。** 原有的 shell 和 agent 通常会继续运行，不过列表发送和自动化启动需要 deck 保持运行。

## 版本范围

本指南适用于 **deck 0.6.6 稳定版**，介绍的功能从 0.6.5 起已提供。0.6.6 改进了 prompt 发送过程中的隐私保护，操作方式没有变化。旧版的功能名称和入口可能不同，可以在设置中查看当前版本；更新的 Nightly 功能暂未收录。

升级、切换通道及旧版数据兼容性，见[更新与版本](/zh/guide/input-and-settings/#更新与版本)。
