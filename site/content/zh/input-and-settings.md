# 输入、设置与排障

这里介绍直接输入终端的本机语音识别、常用快捷键和设置，也整理了录音及更新时可能遇到的问题。

## 用语音向终端输入文字

1. 打开目标 session 和窗格，先看清前台程序，再点击窗格顶栏的麦克风。
2. 说话时，已经确认的文字会直接输入该终端。麦克风下方的浅色字幕表示尚未确认的内容，它还没有输入终端。
3. 再点一次麦克风停止录音。deck 会完成识别并输入余下已确认的文字。你可以在终端里修改，然后自己按回车。

**语音输入不会替你按回车。** 现在没有独立的语音草稿，也没有「仅插入」或「发送」按钮。已经输入终端的文字会保留。受支持的 macOS 26 设备可能边说边输入确认片段；较旧的本机识别方式可能要等说完才输入整段。每次录音最多五分钟，部分系统识别可能更早结束。

切换 session 或窗格、离开 session 视图、隐藏窗口，都会结束录音；尚未送出的文字可能丢失。若无法确认一次输入是否成功，deck 不会自动重发，应先检查原终端。录音也不能证明 agent 已准备好接收内容；权限菜单、编辑器和 shell 提示符尤其要先核对。

识别在 Mac 本机完成；deck 不会把录音或转写内容写入磁盘。已经输入终端的文字仍可能由其中运行的程序按它自己的规则处理。

## 语音无法开始或输入

录音需要受支持的 macOS 12+ 本地识别配置；macOS 26 的兼容设备和语言使用较新的本机识别引擎。首次使用可能需要下载 Apple 的语言资源，未准备好时按提示完成设置。无法在本机识别时，会提示原因，不会改用云端识别。

| 情况 | 处理方式 |
| --- | --- |
| 麦克风权限被拒绝 | 按提示打开系统设置，允许 deck 使用麦克风，再点击麦克风开始录音 |
| 需要语音识别权限 | 在系统设置中允许语音识别，再重试 |
| 系统听写关闭 | 到「系统设置 → 键盘 → 听写」启用，再回到 deck 开始录音 |
| 语言不受支持或资源未就绪 | 选择受支持语言，按系统提示准备资源后重试 |
| 目标窗格或前台程序变化 | 检查原终端，再到正确的窗格开始一次新录音 |
| 无法确认文字是否输入 | 先检查终端，再决定是否重试；deck 不会自动重发 |

权限或听写设置失败时，deck 会给出对应系统设置入口。返回 deck 不会自动开始录音。

在「设置 → 终端与 session → 语音输入」调整常用语言和默认语言，初始提供中文、英文、日文。只启用一种语言时隐藏选择器。「跟随系统语言」不会自动判断你说的语言。语言偏好会保存下来，重启后仍然有效；已有 session 选择的语言只要仍在启用列表中，就会继续保留。

## 常用操作

| 操作 | 入口或快捷键 |
| --- | --- |
| 新建 session | ＋ 新建 session / ⌘N |
| 横向、纵向分屏 | ⌘D / ⌘⇧D，或顶栏分屏按钮 |
| 选择已有 session 进入分屏 | 拖动侧边栏卡片到窗格边缘 |
| 收起侧边栏 | ⌘B |
| 复制与粘贴终端文字 | 拖动选择后 ⌘C / ⌘V |
| 跨屏选择 | 拖动到终端上边缘或下边缘并保持，继续选择历史内容 |
| 使用命令补全 | Tab 或 → 接受灰色建议；只记录 shell 命令，不记录 agent prompt |
| 打开路径或网页 | 点击终端中的已有本地路径或完整 HTTP(S) 链接 |

## 设置与日志

设置分为通用与外观、快捷键、终端与 session、集成与自动化、数据与日志、关于与更新六类，可以搜索名称和说明。

外观提供深色、浅色、跟随系统和高对比度，以及预设强调色；更改会应用到打开的终端窗格。界面语言可选择跟随系统、English 或简体中文。

「数据与日志」可以导出或重置诊断日志。重置需确认，只清空当前日志；命令历史、Shell 恢复数据、已导出的日志和运行中的 session 都不受影响。清除历史与恢复数据使用各自的入口。

向 [GitHub 提交问题](https://github.com/c9r-io/deck/issues/new?template=feedback.yml)时提供版本、通道、复现步骤及预期行为。反馈通常公开，发送前检查截图或导出文件，去掉令牌、私有路径和真实任务内容。

## 更新与版本

本指南适用于 **0.7.8 稳定版**。默认使用 Stable 更新通道；想提前试用候选版本时，可以选择 Nightly，其功能和稳定性可能不同。设置中会显示版本、通道和简短的提交编号。

Stable 和 Nightly 安装在同一位置，共用本地数据和 tmux session，不能当作两个独立应用同时运行。切回 Stable 只改变以后检查的通道，不会自动把更高版本降级。同版本 Nightly 晋升为 Stable 时，安装包保持一致，无需为了通道名称重新安装；若已安装更高版本，则需先核对数据兼容性。

**开启人工检查后，本地数据格式会升级，关闭开关也不会改回旧格式。** 相关队列和设置会升级为 v2，不支持这个格式的旧版无法读取。手动修改版本号或数据格式可能导致误读，不适合作为回退方式。需要回退时，先备份重要数据，确认旧版能否读取；数据备份不会保留正在运行的进程。

完整维护说明见[发布通道文档](https://github.com/c9r-io/deck/blob/692438f9310f079743700a10bda7cf80f77b06c6/docs/release-channels.md)。应用数据与集成的范围见[隐私说明](/zh/privacy/)。
