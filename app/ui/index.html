Automations

Automations open a new session on a clock schedule or a Slack event and send a template. Deck must be running for them to fire.
How runs behave
  • A clock rule skips a slot while its previous card is still on the Board.
  • “Close the card” waits until the agent program exits: a turn ending is not the end of its work, so a live agent keeps its card. With inspection on, nothing closes before the last step is inspected.
  • A newly started agent’s first step waits for you by default; unattended sends to Claude or Codex need the Agent status integration.
  • A channel monitor creates a session on its first match, then only collects later messages into that card.
  • A delivery does not prove business success. Every run creates a fresh session; its command may restore its own context.

Checks that still apply

Real blocking conditions and configured inspection checkpoints still apply, and later steps keep their normal checks. This option covers only a newly started agent’s first step; Deck starts the agent with no prompt bytes.

Ticking this and saving authorizes Deck to send the first step of new runs for future events matching this rule:

  • Scope: each new collection group may start a run; there is no additional limit on the number of runs.
  • Content: the first step may include outside Slack messages; Deck does not verify that content is safe.
  • Risk: before any first interaction, a startup dialog may receive the text and Enter.
  • Not included: Agent tool permissions, or automatic sending of later template steps.
  • After turning it off: only unsent first steps covered by this permission are stopped; Agents keep running and typed text is not retracted.

Applies to runs created from now on, not to existing cards.

Keeping the card

An interactive agent does not exit by itself: its card stays, and this rule’s next slot is skipped. To let a run end on its own, make the template’s last step exit the program.

While the kept card is on the Board, this rule’s next slot is skipped; closing that card resumes it.

Where these apply
  • Left empty: a shell in your home directory, and no command.
