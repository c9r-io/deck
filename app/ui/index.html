Integrations

Slack reactions

A badge you put on a Slack message opens a card through the project’s automations (↻ on the Board). deck never writes to Slack.
Learn more
Opens Slack’s “Create an app” page with everything prefilled (name, user scopes, Socket Mode, the reaction event). Pick a workspace and create it, then: Install App → Install to Workspace → Allow, copy the User OAuth Token below; Basic Information → App-Level Tokens → Generate with connections:write, copy it below. Each token is checked with Slack before it is stored.
Learn more
Tokens are kept in your macOS Keychain, never under ~/.deck, and are never shown again here. The user token finds your badged messages (search, about a minute behind); the app token hears new badges instantly. Only your own reactions count. There is no token without installing the app yourself: Slack has no OAuth redirect to a local app and no API that mints app-level tokens.

Slack channel monitor

Collects only explicitly allowed channels and senders into card scratchpads. It never writes to Slack and cannot backfill gaps.
Learn more
Uses separate least-privilege bot and Socket Mode credentials stored in Keychain. Rules are configured per project under Automations. Disconnects create an explicit unresolved gap; Slack retries are finite.
