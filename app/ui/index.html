deck keeps commands typed in its shells (for the completion chips) in ~/.deck/history.json, readable only by you.
Every 15 seconds, deck may save the current directory and up to 256 KB of plain shell output in private 0600 files. Commands are never replayed; processes, environment and agent screens are not restored.
